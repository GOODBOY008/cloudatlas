# 对象存储

从「成本管理 → 对象存储」打开当前环境的桶清单。原有 `/s3-duplicates` 书签会跳转至 `/object-storage`。页面沿用环境成员权限，桶的资源标识由环境、云账号和云端资源 ID 共同确定。

## 资产和费用

在「资产与关系」选择已有逻辑服务和部署即可绑定。系统与团队来自公共服务目录。服务目录中的「查看关联存储桶」支持反查。多个部署可以引用同一个桶。

默认展示近 30 个自然日（含当天）的日费用。调整日期并点击「应用账期」即可对账。工作区币种用于合计。每笔费用可以展开查看日费用 ID，以及数据源提供的原始账单 ID、导入时间、原币金额和计费项。缺少费用数据时显示待接入；已匹配的零金额账单显示零。归属对账使用以下口径。

- 桶只绑定一个逻辑服务时，其费用归给该服务。
- 共享桶可在「费用与用量」设置按生效日期执行的分摊比例，所有服务合计 100%。在缺少适用规则或绑定的服务集合发生变化时，费用进入待分摊。
- 没有绑定服务的桶与无法匹配桶的账号级账单分别列出。已归属与待分摊、待认领、未匹配的合计等于纳入当前账期和币种的对象存储账单。

## 导入清单

在桶的「优化机会 → 导入对象清单」选择完整快照的覆盖前缀。整桶快照使用空前缀。后台任务验证、解析并原子发布，失败保留最近的成功快照。相同范围、快照时间及内容的重传复用原批次。较新快照中缺少的键从该范围的当前视图移除；重叠前缀和历史版本不会重复计数。只有前缀清单时，覆盖对象数和字节数单列，整桶用量仍待采集。

支持两种输入。

- **厂商完整 CSV 清单**。一并选择原始 manifest.json 和它列出的所有 CSV 或 CSV.gz 数据分片。使用 fileSchema 指定的列顺序，验证源桶、分片大小和 MD5，解码对象键。增量事件日志需要先合成为完整快照。[AWS 清单格式](https://docs.aws.amazon.com/AmazonS3/latest/userguide/storage-inventory-location.html) · [阿里云清单格式](https://help.aliyun.com/zh/oss/user-guide/bucket-inventory)
- **带表头的完整 CSV 或 CSV.gz**。支持 UTF-8，与下列表头匹配。key 必填，表示原始对象键；size 是字节数。提供 version_id 时同时提供 is_latest。布尔值使用 true/false 或 1/0。删除标记与旧版本不计入当前对象。可从页面下载表头。

```csv
key,size,version_id,is_latest,is_delete_marker,etag,full_sha256,storage_class
```

每批上传上限为 32 MiB，解压上限为 96 MiB，最多 250,000 个当前键。更大的数据集可以按互不重叠的前缀分别导出完整清单。对象数为已知零和容量未知是不同状态。

## 解释优化结果

名称相近的桶是核查线索。同文件名、相同 ETag 或仅字节数相同都可以产生待核查的候选，并标出匹配依据。只有大小一致且已提供可比较的整对象 SHA-256 值时，才形成内容一致组。每组可逐页查看相关桶、键、版本、服务、清单时间、覆盖前缀和价格依据。

内容一致组的候选容量按保留一份计算。每个副本都需要有适用于其存储层的每 GiB 每月单价、价格来源，且币种须与工作区一致，才能估算月存储费节省。估算保留成本最高的一份，实际收益还取决于保留要求、最短存储期、取回与请求费，以及处置后的账单。此页面提供核查证据，云端对象的处置由负责人决定。
